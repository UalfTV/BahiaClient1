Acceso Beta

BahiaClient está en fase beta cerrada. Necesitás una clave de acceso para usarlo.

Si no tenés una clave, pedísela al administrador del proyecto. Una vez activada, queda vinculada a esta instalación.

Bienvenido a BahiaClient

Para usar el launcher necesitás verificar tu Discord y elegir tu ID permanente.

1. Verificá tu Discord
Tu nick de Discord se usa como nickname por defecto.
2. Elegí tu ID permanente
Este ID no se puede cambiar. Tus amigos te buscan por acá.
3. Spotify Opcional
Mostrá y controlá tu música desde el cliente.

Elegí tu ID permanente

Tu ID identifica tu cuenta para siempre. No se puede cambiar.
Tus amigos te van a buscar por este ID, y tus stats, logros y clanes van a quedar vinculados a él.

Reglas: 3 a 20 caracteres. Solo letras, números, guiones (-) y guiones bajos (_).
Elegí bien. Una vez confirmado no vas a poder cambiarlo. Si perdés el acceso, vas a poder recuperar la cuenta con un código de respaldo.
